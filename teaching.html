Teaching and workshops

Advanced teaching at the interface of algorithms, scientific software engineering, bioinformatics, and modern Java programming.

Workshop topics

  • Advanced Java for scientific software
    Java, Maven, JavaFX, architecture, concurrency, REST clients, packaging, and deployment.
  • Algorithms in bioinformatics
    Algorithmic foundations for sequence analysis, phylogenetics, networks, and metagenomic analysis.
  • Interactive scientific visualization
    Designing usable tools for complex scientific data, including trees, networks, and 3D structures.
  • AI-assisted scientific programming
    Using AI tools productively while preserving correctness, reproducibility, and technical understanding.

Format

Possible formats include university block courses, 1–3 day workshops, project-oriented training, and focused mentoring for research groups or technical teams.
