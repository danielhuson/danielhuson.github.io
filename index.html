I develop scientific software systems for bioinformatics, phylogenetics, metagenomics, and data visualization. My work combines algorithms, interactive visualization, modern software engineering, and cross-platform application development.

I am the developer of systems including MEGAN, SplitsTree, Dendroscope, PhyloSketch, and related scientific software platforms.

Selected Areas

  • Scientific software systems and visualization
  • Algorithms for phylogenetics and bioinformatics
  • Cross-platform Java and JavaFX application development
  • Interactive visualization of biological data
  • AI-assisted scientific software engineering
  • Mobile scientific applications for iPad and iPhone

Collaborations and Workshops

I am available for selected collaborations involving scientific software engineering, algorithm implementation, visualization systems, modernization of research software, advanced Java development, and technical workshops.

Collaborations may involve: software architecture, GUI and visualization development, deployment and packaging workflows, mobile scientific applications, modernization of legacy scientific software, and integration of advanced algorithms into usable software systems.

Current Focus

Current projects include the next generation of the MEGAN metagenomic analysis platform, interactive phylogenetic visualization systems, mobile scientific applications, and methods for phylogenetic networks and comparative genomics.
