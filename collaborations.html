Collaborations and consulting

I am interested in selective collaborations that combine scientific depth, algorithmic thinking, and practical software engineering.

Possible engagement types

  • Scientific software modernization
    Turning research prototypes into maintainable, documented, distributable software.
  • Algorithm implementation
    Implementing, reviewing, or optimizing methods from scientific publications.
  • Interactive visualization
    Designing JavaFX-based tools for trees, networks, alignments, classifications, and scientific data.
  • Cross-platform deployment
    GitHub workflows, installers, code signing, notarization, and mobile/iOS deployment.
  • Visiting expert engagements
    Short-term visits for software architecture, mentoring, workshops, and collaborative development.

Project models

Depending on the project, an engagement may be a scientific collaboration, a professional consulting project, a visiting expert stay, or a hybrid arrangement involving teaching, travel, and software development.

I am particularly interested in compact, well-defined projects with visible scientific value.
